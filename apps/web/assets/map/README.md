# 지도 자료

`provinces-2020.json`은 통계청 SGIS 2020년 시도 경계를 사용한 [korea-maps 전국 시도 경계 SVG](https://github.com/swcho/korea-maps/blob/main/svg/simple/%EC%A0%84%EA%B5%AD_%EC%8B%9C%EB%8F%84_%EA%B2%BD%EA%B3%84.svg)에서 path와 ID를 추출한 파일입니다. 색상과 클릭 동작은 별도로 적용했습니다. 경계는 2020년 기준이며 최근 행정구역 변경이 반영되지 않았을 수 있습니다. 저장소의 MIT 라이선스는 [LICENSE](LICENSE)에 포함했습니다. 원자료 출처는 통계청 SGIS입니다.

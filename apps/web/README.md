# 도청 계약 분석 웹

사용자 요청으로 React와 Vite를 설치한 웹입니다. 도청 목록 → 분석 순위 → 도청별 상세 근거와 구매 카드 미리보기를 React 상태·컴포넌트로 구현합니다. TypeScript는 아직 사용하지 않습니다.

## 실행

이전에 `python -m http.server`를 실행한 터미널은 Ctrl+C로 종료합니다. 저장소 루트의 VS Code 터미널에서 실행합니다. 각 컴퓨터에서 최초 한 번 `npm.cmd --prefix apps/web ci`를 실행합니다.

```powershell
npm.cmd --prefix apps/web run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 종료는 Ctrl+C입니다. 도청 목록은 API 없이 열리며 구매 카드의 API 모드에는 아래 Python 서버가 필요합니다. 5173 포트가 사용 중이면 임의로 포트를 변경하지 않고 먼저 기존 서버를 종료합니다.

## 파일과 데이터

- `index.html`: React 진입점
- `src/main.jsx`, `src/App.jsx`: React 마운트와 도청 화면
- `src/components/Drawer.jsx`: 상세 패널·닫기·포커스 복귀
- `src/components/PurchasePreview.jsx`: 구매 카드·검색·필터·상세·API 연결
- `src/provinces.js`: 도청 표시용 목록
- `styles.css`: 반응형 배치와 시각 스타일
- `vite.config.js`: 개발·미리보기 서버의 `/api` → `http://127.0.0.1:8000` 프록시

기존 `app.js`·`purchase-preview.js`는 이전 정적 구현 참고용으로 보존하며 현재 진입점에서 실행하지 않습니다. React 컴포넌트가 DOM과 상태를 관리합니다. 배포용 빌드는 `npm.cmd --prefix apps/web run build`, 검사는 `npm.cmd --prefix apps/web test`입니다. `dist/`는 Git 제외입니다. 배포 환경에서는 `/api`를 실제 백엔드로 연결해야 합니다.

목록은 도청명 가나다순입니다. 점수·순위·계약 건수를 생성하지 않으며 미제공 값은 대시·분석 대기로 표시합니다. 비교 기준·판정 방식·집계는 담당 팀원이 제공합니다. 공식 기관 ID·최종 대상 범위·API 형식은 A·B·E와 확인 후 연결합니다. 화면의 key는 API 식별자가 아닙니다. 기존 구매 예제 API를 실제 도청 자료로 표시하지 않습니다.

파일은 UTF-8로 저장합니다. PowerShell에서 한글을 포함한 스크립트를 다른 프로그램에 파이프로 전달할 경우 인코딩이 달라질 수 있으므로 저장된 실제 한글을 확인합니다.

## 구매 카드 1~3단계 확인

메인 페이지 아래 “구매 카드 조회”를 펼치면 기관 간 합성 예제 3건 또는 시중가 예제 1건을 볼 수 있습니다. 정상 비교·자료 부족·조건 확인 필요 상태를 표시합니다. `assets/purchase-examples.json`은 `tests/fixtures/contracts-v1/`의 등록된 분석 응답을 변경 없이 복사한 화면용 묶음이며 원본 파일명이 함께 기록됩니다. 실제 도청 순위와 관계없는 예제입니다.

카드는 데이터의 가격·차액·차이율을 읽어 표시하고 같은 0 기준 축으로 가격 막대를 그립니다. PC 3열·태블릿 2열·모바일 1열이며 사진 대신 물품 아이콘을 사용합니다. 예제 기준일·기간·합성 표시와 카드별 상세 보기를 제공합니다. 현재는 React와 Vite로 실행합니다.

표시 로직 검사는 `node apps/web/purchase-card.test.mjs`로 실행합니다. 브라우저 배치·키보드 검수는 별도로 필요합니다.

## 상세·검색·필터 4~5단계

구매 카드의 기본 모드는 E의 실제 시연 구매 자료 API입니다. API에 저장된 18건은 비교 분석 전이므로 차액은 표시되지 않습니다. 합성 분석 예제는 별도 정적 모드에서 확인합니다. API를 실행하고, 이미 실행 중이었다면 변경된 코드를 읽도록 재시작합니다.

```powershell
.venv\Scripts\python.exe -m uvicorn budget_transparency.api.server:app --app-dir src --host 127.0.0.1 --port 8000
```

Enter·검색 버튼과 기관·품목·상태·비교 유형·정렬 변경은 서버 목록을 다시 조회합니다. 품목 선택 전 차이율 정렬은 사용할 수 없습니다. 조건·결과 수를 표시하며 상세도 선택한 ID와 유형으로 재조회합니다. API를 실행하지 않을 때는 데이터 연결을 “정적 합성 예제”로 바꾸면 같은 등록 예제 내에서 동작합니다. API 오류를 정적 성공으로 자동 대체하지 않습니다.

상세는 대상 가격·비교 표·계산식·포함 비용·기본 설명·출처 카드 순입니다. 생성형 AI는 미연결이라고 표시하고 원본 URL이 없으면 원본 ID를 제공합니다. 패널 스크롤과 네이티브 dialog의 Esc·포커스 제한, 닫기·배경 클릭·포커스 복귀를 사용합니다. 브라우저에서의 키보드 확인은 별도 검수 항목입니다.

# D 도청 화면 검증

대상: `apps/web/index.html`, `app.js`, `styles.css`. 실제 분석 데이터·점수·순위 API는 미연결입니다.

## 실행한 검사

- JavaScript 문법 검사와 문서 링크·공백 검사를 수행합니다.
- 한글이 물음표로 저장된 문제를 발견해 화면과 영향받은 문서를 UTF-8로 복구했습니다. 파일 내용에 실제 한글이 있는지 별도로 검사합니다.
- 이전 DOM 대역 검사에서 상태 필터, 서로 다른 도청 상세, 닫기·포커스 복귀를 확인했습니다. 대역 검사는 브라우저 검수를 대체하지 않습니다.

## 미확인

브라우저의 실제 렌더링, Esc·Tab 동작, 모바일 배치·스크롤은 사람이 확인해야 합니다. 분석값·기관 식별자·출처는 담당 팀원의 데이터 전달 후 검수합니다.

## React 전환 검증

- 사용자 요청으로 React·React DOM·Vite 설치 완료. lockfile을 추가하고 `node_modules/`와 `dist/`는 기존 Git 제외 규칙을 유지합니다.
- `npm.cmd --prefix apps/web run build`: 배포용 빌드 통과. 제이미 이미지와 CSS·JavaScript가 산출물에 포함됩니다.
- `npm.cmd --prefix apps/web test`: 등록 예제·카드 표시 검사와 React 서버 렌더링 검사 통과. 9개 도청·제이미·자료 출처·검색/필터가 렌더링되는지 확인했습니다.
- 임시 Vite 및 API 서버를 실행해 React 모듈 응답과 `/api` 프록시의 검색 결과·시중가 목록/상세 일치를 확인한 뒤 검사 서버를 종료했습니다.
- `python scripts/check_docs.py`, `git diff --check`: 통과. React 전환 후 실제 브라우저의 클릭·Esc·모바일 배치 검수는 미확인입니다.
- 이전 DOM 대역 검사 기록은 이전 정적 구현에 대한 결과이며 React 화면의 상호작용 검수를 대체하지 않습니다.

## 구매 카드 1~3단계 추가

- 새 웹 라이브러리 없이 기존 정적 서버에서 공통 합성 분석 예제 3건을 불러옵니다. 도청 화면 하단의 “구매 카드 미리보기”를 펼쳐 확인합니다.
- `node apps/web/purchase-card.test.mjs`: 원본 fixture와의 동일성, 카드·상세의 +30,000원·+25%, 가격 막대 100%·80%의 공통 축, null·0·음수 구분, 응답 텍스트 이스케이프 통과.
- JavaScript 문법 검사 통과. 임시 로컬 HTTP 서버로 메인 HTML·JS·CSS·합성 JSON·제이미 이미지 응답 200을 확인한 후 검사 서버 종료.
- `python3 scripts/check_docs.py`는 Windows 실행 별칭 접근 오류. `python scripts/check_docs.py`로 동일 검사 통과. `git diff --check` 통과.
- 3/2/1열 반응형 규칙은 구현했으나 브라우저에서의 시각 검수는 미확인입니다. 1단계의 HTTP 실행과 2~3단계 구현을 확인했으며 E와의 공동 검수·실제 기기 확인 완료를 의미하지 않습니다.

## 상세·검색·필터 4~5단계

- 상세에 대상 가격·비교 표·계산식·포함 비용·기본 설명·출처 카드를 표시하고 ID·비교 유형으로 API를 조회합니다. 네이티브 dialog의 스크롤·Esc와 닫기·배경 클릭·포커스 복귀 처리를 구현했습니다.
- Enter·검색 버튼, 기관·품목·상태·비교 유형·정렬 변경 시 API를 재조회합니다. 요청 중 이전 목록을 비우고, 이전 요청을 취소해 늦은 결과가 현재 조건을 덮어쓰지 않게 합니다. 결과 수와 적용 조건을 표시합니다.
- 기관 간 3건·시중가 1건의 등록 합성 예제를 사용합니다. 실제 도청·AI는 미연결입니다. 정적 조회는 별도 모드로 명시적으로 선택합니다.
- `.venv\Scripts\python.exe -m unittest discover -s tests/unit -p test_fixture_server.py -v`: 5개 통과. 검색·필터·유형별 목록/상세 일치·페이지·잘못된 요청 거절·비교군 유지 확인.
- `node apps/web/purchase-card.test.mjs`: 시중가 가격·판매처·비용·기본 안내와 필터 검사 통과.
- `node apps/web/purchase-preview.test.mjs`: DOM 대역을 사용해 API 검색 제출·유형 전환·상세 ID/유형 요청·닫기/포커스·요청 실패 안내 통과.
- 임시 로컬 서버로 웹 리소스 HTTP 200, 기관 간·시중가 목록/상세 일치와 CORS 헤더를 확인한 뒤 검사 서버 종료.
- 문서 링크 및 공백 검사 통과. 실제 브라우저의 Esc·Tab 포커스 제한·배경 클릭·모바일 스크롤은 미확인입니다.

## 전수 대조

1. **쇼핑몰 품목 원본.** 9개 기관 × 13개 달력 구간의 117개 조회에 대해 총 121페이지의 순번, 응답 건수 합계, 대상 기관, 기간, 최종차수 표시를 검사했다. 원본 23,611행에서 공사·용역 분류 741행을 제외했다. 두 자리 상위분류 10~60은 물품, 70~94는 공사·용역으로 분류했고, 99로 시작하는 분류는 원본 품명을 따로 확인해 물품 13개 분류와 일반용역 99080102를 구분했다. 기관·요구번호 또는 계약번호·차수·물품순번 기준으로 원본 중복은 0행이었다. 채택한 22,870행은 납품요구 20,414행과 총액계약 2,456행이다. 정제 후 원본 위치에서 기관·날짜·품목·수량·단가·단위·차수를 다시 읽어 일치 여부를 확인했다.
2. **납품요구 대조.** 같은 기간의 요구서 10,514개 차수에서 최종 요구서 키 9,185개를 추출했다. 9,185개 모두 품목 원본에 있었다. 품목 원본의 요구서 키 중 헤더 조회에 없는 115개는 자체조달로 표시됐다. 경기도 2026년 10월은 요구서 35개를 상세 API로도 각각 조회했다. 원본 49품목행 중 이전 차수 2행을 제외한 47행이 품목 조회의 납품요구 47행과 일치했다. 그중 1행은 용역 분류였다.
3. **공식 보고서 교차 확인.** 9개 기관의 조달데이터허브 보고서에는 24,302행이 있었다. 그중 최종 표시 Y인 20,788행을 API 품목 원본과 대조했다. 20,766행은 요구번호·차수·순번·기관코드·식별번호·날짜·수량단위·품목금액이 일치했다. 수량 1,919행과 단가 8행은 보고서의 정수 반올림으로 표시 차이가 생겨 API 소수를 보존했다. 남은 22행은 요구번호 7개로 다시 조회했다. 모두 11월 13일 새 차수로 대체된 행이었다. 보고서는 쇼핑몰 납품요구 범위라서 이 수치를 총액계약의 검증 건수에 더하지 않는다. [공식 원본 보고서](https://data.g2b.go.kr/link/AISC001_01/?reptNm=UI-ADOXAA-038R)
4. **보조 계약의 추가·보류.** 물품계약 원장에만 있는 기초계약 162개의 상세를 조회했다. 같은 기초계약의 최신 차수와 해당 차수의 중복 통합번호를 확인했고, 각 대표 통합번호의 삭제 이력 및 직후 차수를 재조회했다. 두 조회 모두 162개에서 추가 행이 없었다. 원본 184품목행 중 117행은 기관·계약일·품명·수량·단가를 추적했다. 62행은 단가·협약 계약의 주문 수량을 확인할 수 없었고, 3행은 수량×단가와 원본 품목금액이 1원 이상 달랐다. 2행은 양수인 품목값을 확인할 수 없었다. 이 67행은 원본 위치와 사유를 별도 보관했다. 원본에 금액 열과 수량 열이 함께 보이는지만으로 구매 수량을 확정하지 않았다.
5. **계약과정.** 물품계약 원장은 기관코드 10개(무안청사 구·현 코드 각각 포함)로 53개 주간 구간 전체를 조회했다. 고유 통합계약번호 2,816개 중 1,057개는 입찰공고/조달요청 조회 후 통합공개 원본의 확정계약번호와 본청명까지 일치했다. 나머지 1,759개는 원장에 공고·요청 조회번호가 없었다. 같은 확정계약번호로 묶으면 본청별 2,398개이며 873개가 연결된다. 공고번호 712개, 공고·차수 742개 중 477개에 발주계획번호, 435개에 사전규격번호, 710개에 낙찰 목록, 712개에 계약 목록이 있었다. 개별 구매 품목행 중 계약 원장과 정확히 연결된 행은 2,518행, 공고·차수까지 연결된 행은 819행이다. 공개 과정의 끝은 계약이며 납품검수·지급일은 확인하지 못했다.
6. **정제본과 시연본.** `record_id` 22,987개가 고유하고 같은 수의 행별 근거가 있다. 두 자료원 간 총액계약 중복은 기초번호까지 검사했다. 아래 시연 18행은 연간 정제본과 같은 레코드다. 정밀도로 인해 수량·단가를 십진 문자열로 보관했다. 원문에 0으로 적힌 수량 1,471행과 단가 4행을 보존했다. 물품 식별번호 미기재는 11행, 단위 미기재는 175행이다. 모델 미확인은 null, 유효·취소·지급 상태가 확인되지 않은 구매는 unknown이다. 세금 포함은 계약·규격·적용일이 일치한 6행만 true다. 배송·설치비 포함은 미확인이다.

독립 검수에서도 서로 다른 자료원의 기초계약 중복과 내부 ID 중복은 각각 0건이었다. 보조 원본 107개 계약의 채택 품목 117행과 쇼핑몰 품목 22,870행을 정제본에서 다시 찾았고, 시연본 18행은 연간 정제본과 전 필드가 일치했다. 검수 결과는 로컬 원본 폴더의 `final-purchase-check.json`에서 확인할 수 있다.

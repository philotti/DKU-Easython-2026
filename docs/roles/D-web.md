# D · 사진처럼 카드 목록과 상세 패널 만들기

담당자: 미정. 목표는 참고 사진과 같은 정보 배치를 구현하는 것입니다. 서버와 API 키 설정은 E가 담당하며, D는 공통 예제로 화면을 먼저 완성합니다.

## 만들어서 전달할 것

| 만들 파일 (React를 채택할 경우의 제안 경로) | 넣을 화면 |
|---|---|
| `apps/web/src/App.tsx` | 검색·목록·선택한 카드 상태 |
| `apps/web/src/components/SearchBar.tsx` | 검색 입력·버튼 |
| `apps/web/src/components/FilterBar.tsx` | 기관·품목·비교 유형·상태·정렬 |
| `apps/web/src/components/PurchaseCard.tsx` | 카드 하나 |
| `apps/web/src/components/PriceBars.tsx` | 두 단가 비교 막대 |
| `apps/web/src/components/PurchaseDrawer.tsx` | 오른쪽 상세 패널 |
| `apps/web/src/components/EvidenceCard.tsx` | 원본 출처와 가격 근거 |
| `apps/web/src/styles.css` | 색·여백·반응형 배치 |

파일 확장자와 생성 방법은 E가 선택한 화면 환경에 맞춥니다. 다른 스택이면 E가 대응 경로를 적어줍니다.

## 작업 순서

### 1. 화면이 실행되는지 확인하기

E가 만든 기본 화면을 자신의 노트북에서 엽니다. 설치·실행 명령은 E에게 받고 실행 실패 메시지를 그대로 전달합니다. 화면이 열리기 전에는 새 라이브러리를 임의로 추가하지 않습니다.

### 2. 카드 하나 만들기

[화면 명세](../screen-spec.md)의 합성 예제를 사용합니다. 상태, 품목명, 기관명, +30,000원·+25%, 두 가격 막대, 근거 수, 자세히 버튼을 배치합니다. 흰 배경·얇은 테두리·둥근 모서리·주황색 강조를 적용합니다. 숫자를 코드에 고정하지 말고 카드가 받은 데이터에서 읽습니다.

### 3. 카드 목록 만들기

E의 예제 배열을 반복 표시합니다. PC 3열, 중간 2열, 모바일 1열로 바뀌게 합니다. 사진이 없는 카드는 아이콘으로 보여줍니다. 상단에 기준일과 합성 예제 표시를 넣습니다.

### 4. 상세 패널 만들기

자세히 버튼을 누르면 클릭한 구매의 상세 패널이 열리게 합니다. 대상 가격·비교 대상 표·계산식·포함 비용·AI 설명·출처 카드를 순서대로 넣습니다. 사진 2·3처럼 패널 안에서 스크롤하게 합니다. 닫기·Esc·배경 클릭과 포커스 복귀를 확인합니다.

### 5. 검색과 필터 연결하기

입력 후 Enter/검색 버튼으로 E의 조회 함수를 부릅니다. 기관·품목·상태·비교 유형을 바꾸면 결과를 다시 요청합니다. 검색 조건과 결과 수를 표시합니다. 비교 유형이 바뀌면 막대 이름도 기관 중앙값/시중가로 바뀌어야 합니다. 다른 품목을 기관 순위처럼 섞어 정렬하지 않습니다.

### 6. 실패 화면 만들기

로딩, 검색 결과 없음, 비교 자료 부족, 조건 불명, 서버 오류, AI 기본 설명을 각각 표시합니다. null 금액을 0원으로 바꾸지 않습니다. 원본 링크가 없으면 링크 버튼 대신 원본 식별자를 보여줍니다.

### 7. 실제 연결과 눈으로 검수하기

E가 실제 API로 바꾸면 같은 카드 코드를 사용합니다. A에게 출처·기관명 검토, B에게 숫자 검토를 요청합니다. 좁은 화면에서 금액이 잘리지 않는지, 카드별로 다른 상세가 열리는지 확인합니다. 마지막으로 검색부터 원본 확인까지 화면을 녹화합니다.

## 완료 확인

- [ ] 목록이 참고 사진처럼 카드 형태로 보인다.
- [ ] 클릭한 카드에 맞는 오른쪽 패널이 열린다.
- [ ] +30,000원·+25% 예제가 카드와 상세에서 같다.
- [ ] 시중가 없음·비교 자료 부족을 명확히 표시한다.
- [ ] 키보드·모바일에서도 주요 동작이 가능하다.

## 막혔을 때 전달할 내용

어느 단계인지, 파일 경로, 입력, 기대 결과, 실제 오류를 E와 관련 담당자에게 전달합니다. 인증키는 지웁니다. 없는 데이터나 기능을 완료된 것처럼 만들지 않습니다. [공통 역할 안내](README.md)와 [완성 화면 명세](../screen-spec.md)를 기준으로 확인합니다.

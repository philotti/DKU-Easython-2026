# 가격 비교 규칙 v1

담당 B, 데이터 확인 A, 연결 E. **가격 차이 계산 규칙이지 통계적 이상치·부패 판정 규칙이 아닙니다.** `policy.schema.json` 형식의 정책을 서버 설정으로 읽습니다. B의 함수는 기존 네 인자를 유지하고, 같은 정책을 사용하는 분석 모듈을 E가 초기화합니다. 요청마다 사용자 입력으로 정책을 임의 변경하지 않습니다.

## 정책 파일

`tests/fixtures/contracts-v1/policy.json`은 합성 예제용입니다. 실제 분석은 `data/demo/comparison-policy.json`을 A·B·E가 실제 범위에 맞춰 만들고 policy_id를 다르게 붙입니다. 기간은 포함 경계이며 기관 비교는 구매일, 시중가는 확인일의 한국 날짜를 사용합니다. 시작일은 종료일 이하여야 합니다.

min_peer_records와 min_peer_agencies는 비교 가능한 최소 구매 건수·다른 기관 수입니다. 예제는 각각 3입니다. 이는 통계적 신뢰성 기준이 아니며 실제 자료의 최소 표본을 정당화하지 않습니다. 실제 정책 미등록 시 unavailable과 사유를 반환합니다.

## 포함 규칙

- 대상이 active, 양의 단가·수량, 유효 날짜를 가져야 합니다. 취소·이전 변경본은 제외합니다. 중복 계약의 최신 유효본 선택은 A가 정리합니다.
- 물품 ID·모델·규격·단위·통화가 확인되어 같아야 합니다. 누락은 같은 값으로 간주하지 않습니다.
- 세금·배송·설치 포함 값은 모두 확인되어 같아야 합니다. null은 조건 불명입니다.
- 기관 비교는 대상 기관을 제외하고 동일 수량, 정책 기간 내 구매만 사용합니다.
- 시중가는 동일 판매 단위와 조건, 정책 확인 기간 내 자료를 사용합니다. 한 판매처·제품의 최신 확인 기록 하나만 사용하며 동률은 ID순으로 하나를 고릅니다. 실제·합성 자료를 섞지 않습니다.

## 계산

기관 간 기준은 적격 구매 건별 단가 중앙값, 시중가 기준은 적격 판매처 가격 중앙값입니다. 기관 비교는 정책의 두 최소값을 모두 만족해야 하며, 시중가는 확인된 판매처 하나 이상이면 계산하되 적은 표본이라는 한계를 표시합니다.

Decimal로 계산합니다. 기준값과 차액은 정확한 십진 문자열, 차이율만 소수 둘째 자리까지 ROUND_HALF_UP으로 반올림합니다. `difference = target.unit_price - reference_unit_price`, `difference_pct = difference/reference_unit_price*100`. 기준값이 0 이하이면 계산 불가입니다. 원화 표시 반올림은 화면에서 하되 원래 값을 상세에 보존합니다.

## 상태 우선순위

1. unavailable: 정책 없음, 대상 취소·이전 변경본·상태 unknown, 가격·수량 누락/비양수, 대상 날짜 부적합.
2. conditions_unknown: 대상의 제품 식별·비교 조건이 불명.
3. insufficient_data: 적격 비교군이 최소 기준 미달. 비교 후보 조건 불명도 제외 이유로 기록.
4. comparable: 위 조건 충족.

비교 불가에서는 기준·차액·차이율이 null입니다. 선택된 적격 비교 기록은 표본이 부족해도 반환할 수 있으며 표본 수는 실제 목록 길이와 같아야 합니다. 제외 기록은 ID와 이유를 반환합니다. 설명의 근거 ID는 대상과 선택된 비교 기록 ID만 사용합니다.

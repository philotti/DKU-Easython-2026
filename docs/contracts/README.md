# 공동 계약 v1 — 팀이 그대로 사용할 약속

2026-11-13 사용자 요청으로 **내부 계약 1.0을 고정**했습니다. 실제 공공 API 형식과는 별개입니다. 서비스는 아직 구현되지 않았고 예제는 모두 합성입니다. 실제 데이터는 A가 이 형식으로 변환합니다.

## 처음 할 일

1. [예제 모음](../../tests/fixtures/contracts-v1/README.md)을 열어 자기 역할의 파일을 확인합니다.
2. A는 [데이터 계약](data-model.md), B는 [비교 규칙](comparison-policy.md), C·D·E는 [API 계약](analysis-api.md)을 읽습니다.
3. 같은 예제로 개발하고 아래 검사를 실행합니다.

```bash
python3 -m pip install -r requirements-dev.txt
python3 scripts/check_contracts.py
```

설치는 최초 한 번 필요합니다. 스키마는 필수 필드·타입·허용값·추가 필드 금지를 검사합니다. 스크립트는 예제의 수치·근거 참조·표본 수를 추가 확인합니다. 실제 공공데이터 의미와 AI 설명의 사실성까지 자동 보장하지 않습니다.

## 변경 규칙

필드명·타입·상태를 각자 바꾸지 않습니다. E에게 필요한 변경을 설명하고 생산자·소비자가 함께 검토합니다. 문서·스키마·예제·검증을 같이 바꿉니다. 호환이 깨지면 계약 버전을 올리고 기존 화면·데이터도 갱신합니다.

비교 정책의 기간·표본 수는 별도 정책 파일입니다. 이를 바꿔도 데이터 필드 형식은 유지할 수 있습니다. 실제 데이터에 없는 정보는 null로 두며 비교 가능으로 억지 판정하지 않습니다.

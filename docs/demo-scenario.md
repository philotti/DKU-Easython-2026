# 발표자가 따라 하는 시연 순서

발표자는 미정입니다. A는 출처·발표 근거, B는 숫자, C는 AI 동작과 한계, D는 화면·녹화, E는 실행·제출을 담당합니다. 실제 데이터가 확보되면 아래 대괄호 내용을 확인된 값으로 채웁니다. 현재는 시연 결과가 아닙니다.

## 시작 전 준비

- A: [시연 품목], [구매 기관], [데이터 기준일], 원본 위치를 준비.
- B: [대상 단가], [비교 기준], [차액], [차이율], 비교 목록을 확인.
- C: 실제 자료에 맞는 질문 하나와 기본 설명 전환 방법을 준비.
- D: 카드와 패널, 모바일 화면, 백업 녹화를 준비.
- E: 발표 PC에서 실행, 키 비노출, 제출 형식과 배포 필요 여부 확인.

## 화면 조작과 설명

| 순서 | 실제 행동 | 발표할 내용 | 확인 담당 |
|---|---|---|---|
| 1 | 목록 화면의 기준일 표시 | “공개 자료를 시민이 비교하고 원본으로 확인하도록 만들었습니다.” | A·D |
| 2 | 기관·품목 검색 또는 자연어 질문 | 해석된 조건과 검색 범위 설명 | C·E |
| 3 | 구매 카드에서 두 막대 가리키기 | 구매 단가와 비교 기준이 각각 무엇인지 설명 | B·D |
| 4 | 자세히 보기 클릭 | 오른쪽 패널에 같은 수치가 나오는지 확인 | D |
| 5 | 비교 기록·계산식·조건 펼쳐 보기 | 어떤 자료를 포함·제외했는지 설명 | A·B |
| 6 | AI 설명 확인 | “계산은 코드가, 설명은 근거를 받은 AI가 합니다.” | C |
| 7 | 원본 열기 | 실제 가격과 계약 정보를 직접 확인 | A |
| 8 | 자료 부족 사례 열기 | “확인할 수 없는 자료는 판정을 유보합니다.” | B·D |

시중가가 검증되었다면 비교 유형을 바꿔 판매처·확인일·포함 비용을 보여줍니다. 없으면 시중가 없음 상태를 보여주고 기관 간 비교까지만 구현했다고 설명합니다.

## 장애 대응

AI 연결이 안 되면 기본 설명으로 전환하고 현재 AI 연결 상태를 설명합니다. 서버 장애 때 녹화를 사용할 경우 녹화임을 밝힙니다. 합성 자료로 시연하면 화면과 발표 모두 예시임을 표시합니다. 원본 연결이 없으면 가짜 URL 대신 데이터셋 위치·원본 ID를 보여줍니다.

## 발표에서 말하지 않을 것

가격 차액을 확정 절감액이라고 말하지 않습니다. 기관을 비리 기관이라고 부르지 않습니다. 직접 학습하지 않은 모델을 학습했다고 설명하지 않습니다. 미완료 기능·검증을 완성했다고 말하지 않습니다.

# 완성 화면 명세 — 참고 사진을 우리 서비스로 구현하기

사용자가 올린 세 장의 사진을 기준으로 **흰 배경·둥근 카드·주황색 비교 막대·오른쪽 상세 패널**을 구현합니다. 사진 속 로고·정당 필터·사용자 순위는 가져오지 않습니다. 이 문서는 구현 명세이며 현재 화면이 완성되었다는 뜻은 아닙니다.

## 1. 목록 화면: 사진 1

위에서 아래로 다음 순서로 만듭니다.

1. 헤더: 임시 서비스명 “공공계약 가격 비교”, “공개된 구매 내역을 같은 기준으로 비교합니다” 한 줄.
2. 데이터 안내: 기준일·대상 기간·품목 범위, 합성 예제이면 “화면 개발용 예시 데이터” 배너.
3. 검색창: “기관이나 물품을 입력하세요”와 검색 버튼. Enter로도 검색.
4. 필터: 기관 선택, 품목 선택, 비교 유형(기관 간 / 시중가), 상태(전체 / 비교 가능 / 자료 부족 / 조건 확인 필요).
5. 결과 수와 정렬: 기본은 구매일 최신순, 선택하면 동일 품목·비교 유형 안에서 양의 차이율 큰 순. 비교 불가 값은 뒤로 보냄.
6. 카드 목록: 넓은 PC 3열, 좁은 PC·태블릿 2열, 모바일 1열.

### 카드 하나에 넣을 것

- 위: 상태 배지와 구매일.
- 품목명, 모델·규격, 구매 기관명. 사진이 없으면 중립적인 물품 아이콘. 외부 상품 사진을 임의 복제하지 않음.
- 강조 상자: “비교 기준 대비 단가 차이”와 `+30,000원 (+25%)` 같은 수치.
- 첫 막대: “기관 구매 단가”와 금액, 주황색.
- 둘째 막대: “다른 기관 구매 단가 중앙값” 또는 “확인된 시중가”, 회색.
- 막대는 동일한 0 기준 축으로 그립니다. 두 값의 최대값 대비 비율을 사용하고 작은 값을 과장하지 않습니다.
- 아래: 비교 건수·기관 수·출처 수, “자세히 보기” 버튼.

비교 유형을 바꾸면 기준값·차이·근거가 함께 바뀝니다. 시중가 자료가 없으면 “확인된 시중가 없음”을 표시하고 다른 기관 가격을 시중가로 부르지 않습니다. 가격 차이를 낭비 금액·확정 절감액으로 쓰지 않습니다.

## 2. 상세 패널: 사진 2·3

카드의 자세히 보기를 누르면 배경이 어두워지고 오른쪽 패널이 열립니다. PC에서는 화면 폭 약 절반, 모바일에서는 전체 폭을 사용합니다. 패널 내부를 스크롤합니다.

표시 순서:

1. 닫기 버튼, 품목명·모델·식별번호·구매 기관·구매일.
2. 사진 또는 아이콘.
3. 단가 차이와 차이율 강조 상자.
4. 상태 설명: 비교 가능인지, 부족하거나 확인하지 못한 조건은 무엇인지.
5. 대상 구매 내역: 수량·단위·단가·계약 식별자. 총액이 있으면 그 의미를 확인한 값만 표시.
6. 비교 근거 목록: 다른 기관의 구매일·수량·단가 또는 판매처의 확인 가격과 확인 날짜.
7. 포함 조건: 부가세·배송·설치 각각 포함/미포함/확인 불가.
8. 계산식과 실제 대입 값, 비교 대상 수·기간·제외 이유.
9. AI 설명: “확인된 차이 / 비교의 한계 / 추가로 확인할 사항”. 기본 설명을 쓰면 “기본 안내” 표시.
10. 출처 카드: 제공기관·원본 식별자·수집일·“원본 열기” 버튼. 실제 URL이 없으면 링크를 만들어내지 않고 데이터셋 위치와 원본 ID 제공.

닫기 버튼·배경 클릭·Esc로 닫을 수 있어야 합니다. 열린 동안 키보드 포커스가 패널 안에 있고 닫으면 원래 버튼으로 돌아오게 합니다.

## 3. 눈으로 확인할 개발용 예시

모든 이름·가격은 합성 예시입니다. 실제 기관 분석이 아닙니다.

- 예시기관 A: 같은 제품 150,000원.
- 예시기관 B/C/D: 동일 조건 100,000 / 120,000 / 140,000원.
- A의 비교 기준: 다른 기관 세 구매의 중앙값 120,000원.
- 카드: 구매 단가 150,000원, 비교 기준 120,000원, +30,000원, +25%.
- 상세: 위 세 비교 근거를 그대로 보여줍니다. 합성 예제의 원본 URL은 null.
- 다른 규격의 예시 물품: “조건 확인 필요”; 부족한 표본: “자료 부족”. 계산 불가를 0원으로 표시하지 않습니다.

## 4. 완성 확인

- [ ] 참고 사진처럼 카드 목록과 오른쪽 상세 패널이 모두 있다.
- [ ] 카드와 상세 패널의 숫자가 같다.
- [ ] 필터·정렬·검색을 바꾸면 실제 결과가 바뀐다.
- [ ] 카드 하나의 원본과 비교 근거까지 따라갈 수 있다.
- [ ] 자료 없음·조건 불명·AI 실패·로딩·서버 오류를 서로 구분한다.
- [ ] 좁은 화면에서도 금액·버튼·출처가 잘리지 않는다.
- [ ] AI 설명이 늦거나 실패해도 수치와 출처는 보인다.

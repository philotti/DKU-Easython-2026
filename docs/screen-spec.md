# 도청 계약 분석 화면 명세

사용자 요청으로 구매 검색·카드 중심에서 도청 목록 → 분석 순위 → 도청별 상세 근거 구조로 변경합니다. 비교 기준은 담당 팀원이 전달하며 현재는 화면 뼈대만 제공합니다.

사용자 요청으로 React·Vite를 설치했습니다. 현재 진입점은 `apps/web/src/main.jsx`이며 도청 화면은 `src/App.jsx`, 구매 화면은 `src/components/PurchasePreview.jsx`에서 관리합니다. Vite의 `/api` 프록시로 E의 서버에 연결합니다. 기존 정적 스크립트는 현재 화면에서 실행하지 않습니다.

## 도청 목록

상단 서비스명은 “세금탐지기-도청감지”이며 목록·분석 순위·자료 출처 메뉴를 둡니다. 별도 소개 제목과 요약 지표 없이 바로 도청 목록을 표시합니다. 도청 버튼은 가나다순으로 PC 3열·태블릿 2열·모바일 1열 배치합니다. 목록은 화면용이며 최종 기관 범위와 식별자는 A·E와 확인합니다.

## 분석 순위

순위 표 옆에 제이미의 요약 영역을 둡니다. 첨부 캐릭터 이미지는 `apps/web/assets/jamie.png`로 연결하며 파일이 없으면 이름의 첫 글자로 표시합니다. 실제 분석과 요약은 아직 미연결이므로 준비 중 안내만 표시합니다. 후속 요약은 등록된 분석값과 근거만 설명합니다.

순위·도청·분석 계약 수·이상치 계약 수·점수·상태·상세 보기 열을 둡니다. 현재는 순위 없이 가나다순으로 표시하며 전체·분석 완료·분석 대기 필터를 제공합니다. 분석 완료 필터에는 빈 안내를 표시합니다.

기간·비교군·최소 표본·이상치 판정·집계 방식과 근거를 받은 뒤 실제 순위를 연결합니다. 임의 점수와 행 번호를 순위로 표시하지 않습니다. 기존 계약 v1은 변경하지 않으며 순위 API는 후속 합의합니다.

## 자료 출처

상단 “자료 출처” 메뉴는 같은 페이지의 출처 영역으로 이동합니다. 자료명·제공 기관·대상 기간·수집일·이용 조건·원본 링크를 담는 표를 제공합니다. 현재는 등록 대기 상태이며 실제 출처나 링크를 임의로 넣지 않습니다. 좁은 화면에서는 표를 가로 스크롤합니다.

## 도청별 상세 근거

목록과 표에서 같은 도청의 오른쪽 패널을 엽니다. 도청명, 순위·점수·계약 수, 분석 개요, 이상치 계약 내역, 비교 계약·제외 사유·출처 영역을 둡니다. 미제공 값은 대시·자료 연결 전으로 표시하며 정상·이상으로 판정하지 않습니다.

모바일에서는 전체 너비를 사용합니다. 닫기·Esc·배경 클릭·포커스 복귀를 지원합니다. 이상치가 위법·예산 낭비를 의미하지 않는다는 설명을 유지합니다.

## 검수

기존 역할 문서의 1~5단계 확인용으로 메인 하단에 접을 수 있는 “구매 카드 미리보기”를 둡니다. 기관 간 합성 분석 3건·시중가 1건을 변경 없이 유형별로 사용하고 도청 순위와 구분합니다. 카드에는 상태·품목·기관·차액·차이율·두 가격 막대·근거 수·자세히 보기를 표시합니다. 정상 기관 비교 예제는 +30,000원·+25%이며 자료 부족과 조건 불명은 null을 유지합니다. 기준일과 합성 안내를 표시하며 PC 3열·태블릿 2열·모바일 1열로 배치합니다.

API 모드에서 검색·필터·유형 변경 시 목록을 재조회하고 상세도 ID·유형으로 요청합니다. 정적 모드는 명시적으로 선택할 수 있으며 같은 예제에서 로컬 필터를 수행합니다. 품목 선택 시에만 차이율 정렬을 활성화합니다. 상세는 대상 가격·비교 표·계산식·포함 비용·기본 설명·출처 순으로 표시합니다. AI 미연결을 공개하며 가격이나 원본 링크를 만들지 않습니다.

서로 다른 도청의 상세, 상태 필터, 키보드와 모바일 조작을 확인합니다. 분석값·원본 근거 일치는 데이터 연결 후 확인합니다.

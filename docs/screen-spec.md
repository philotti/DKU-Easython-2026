# 도청 계약 분석 화면 명세

지역 지도에서 본청의 구매 내역을 선택하고, 아래에 자료 출처를 표시합니다.

React·Vite를 사용합니다. 현재 진입점은 `apps/web/src/main.jsx`이며 도청 화면은 `src/App.jsx`, 구매 화면은 `src/components/PurchasePreview.jsx`에서 관리합니다. Vite의 `/api` 프록시로 E의 서버에 연결합니다. 기존 정적 스크립트는 현재 화면에서 실행하지 않습니다.

## 지역별 구매 지도

2020년 SGIS 기반 시도 경계를 표시용 지도로 사용하며 기준 연도와 출처를 화면에 명시합니다. 최근 행정구역 변화가 반영되지 않았을 수 있습니다. 구매 자료가 있는 12개 지역만 선택할 수 있습니다. 도청별 참고 기준보다 높은 구매 비율 꺾은선 그래프는 지역 선택 전에도 표시합니다. 지도 또는 지역 버튼을 선택하면 오른쪽 상세 창에 해당 본청의 월별 구매 기록 비율 꺾은선 그래프와 구매 내역을 표시합니다. 그래프는 각 지역에서 참고 계산이 된 건 중 기준보다 높은 건의 비율을 꺾은선으로 표시합니다. 지역별 표본 수와 품목 구성이 다르며 기관 평가나 시간 추세가 아닙니다. 지역을 선택하기 전에는 구매 내역을 표시하지 않습니다. 2020년 경계 지도에서 광주와 전남을 선택하면 모두 전남광주특별시의 무안청사 자료로 연결됩니다. 광주청사 자료는 포함하지 않습니다. 지도 경계와 기관별 구매 범위를 혼동하지 않도록 안내합니다.

## 자료 출처

상단 “자료 출처” 메뉴는 같은 페이지의 출처 영역으로 이동합니다. 자료명·제공 기관·대상 기간·수집일·이용 조건·원본 링크를 담는 표를 제공합니다. 현재 구매 자료의 조달청 공공데이터포털 출처와 판매처별 시중가 확인 방법을 표시합니다. 좁은 화면에서는 표를 가로 스크롤합니다.

## 도청별 상세 근거

도청 목록에서 도청의 오른쪽 패널을 열고, 참고 차이율 순위 표에서는 해당 구매의 상세 근거를 엽니다. 도청명, 순위·점수·계약 수, 분석 개요, 이상치 계약 내역, 비교 계약·제외 사유·출처 영역을 둡니다. 미제공 값은 대시·자료 연결 전으로 표시하며 정상·이상으로 판정하지 않습니다.

모바일에서는 전체 너비를 사용합니다. 닫기·Esc·배경 클릭·포커스 복귀를 지원합니다. 이상치가 위법·예산 낭비를 의미하지 않는다는 설명을 유지합니다.

## 검수

기존 역할 문서의 1~5단계 확인용으로 메인 하단에 접을 수 있는 “구매 내역 조회”를 둡니다. 정적 모드는 기관 간 합성 분석 3건·시중가 1건을 유형별로 사용하고 도청 순위와 구분합니다. 기본 API 모드는 연간 구매 데이터를 조회하며, 참고 비교 가능 기록부터 표시하고 전체 건수와 참고 비교 가능 건수를 표시합니다. 카드에는 상태·품목·기관·차액·차이율·두 가격 막대·근거 수·자세히 보기를 표시합니다. 정상 기관 비교 예제는 +30,000원·+25%이며 자료 부족과 조건 불명은 null을 유지합니다. 기준일과 합성 안내를 표시하며 PC 3열·태블릿 2열·모바일 1열로 배치합니다.

API 모드는 실제 구매 자료의 조건 미확인 참고 비교를 조회하며 비교 자료가 없으면 그 사유를 표시합니다. 정적 모드는 합성 예제입니다. API 모드에서 검색·필터·유형 변경 시 목록을 재조회하고 상세도 ID·유형으로 요청합니다. 정적 모드는 명시적으로 선택할 수 있으며 같은 예제에서 로컬 필터를 수행합니다. 품목 선택 시에만 차이율 정렬을 활성화합니다. 상세는 카드와 같은 기준의 단가·차이 요약, 확인 사항과 검증 가능한 원본 출처를 표시합니다. AI 요청은 지역별 창의 구매 기록 보고서에서만 제공하며, 기본 집계는 코드가 작성하고 AI는 허용된 확인 사항을 선별합니다. 가격이나 원본 링크를 만들지 않습니다.

서로 다른 기관의 상세, 상태 필터, 키보드와 모바일 조작을 확인합니다. 분석값·원본 근거 일치는 데이터 연결 후 확인합니다.

기관 표시는 전남광주통합특별시 무안청사를 요청한 명칭인 전남광주특별시로 줄여 표시합니다. 구매 원본의 기관명과 기관코드는 보존하며 상세 출처에서 원본 기관명을 확인할 수 있습니다. 데이터 범위는 무안청사이며 광주청사·동부청사는 포함하지 않습니다.

지도에서 선택한 본청은 월별 구매 품목 기록 비중도 표시합니다. 기간 양 끝의 부분월과 2026년 12월 자료 부재와 서울·부산·대전의 2025년 11월 이전 자료 부재를 안내합니다. 구매 품목 수는 지출액·계약 건수가 아니며 예산 소진 여부의 판단 근거로 사용하지 않습니다.

지역별 보고서는 완전한 월 중 구매 품목 기록이 많은 달, 같은 날짜·품목명으로 기록이 많은 사례와 참고 단가 비교 현황을 코드로 요약하고, 해당 날짜의 원본 식별자 최대 10개를 보여줍니다. 사용자가 명시적으로 요청할 때만 AI가 검토할 확인 사항을 선택하며, 월별 지출 금액과 연말 예산 소진 여부는 데이터가 부족해 판정하지 않습니다.

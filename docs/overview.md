# 프로젝트 개요

## 시민에게 제공할 것

공공기관이 같은 물품을 얼마에 구매했는지 비교하고, 계산 과정과 원본을 한 화면에서 확인하는 웹 서비스입니다. 공개 자료를 시민이 읽고 검증하기 쉬운 형태로 바꾸는 것이 목적입니다.

시민은 기관·품목을 검색하고 구매 카드를 누른 뒤, 오른쪽 패널에서 비교 가격·조건·출처를 확인합니다. 모바일에서는 패널이 전체 폭으로 열립니다. 상세한 표시 항목은 [화면 명세](screen-spec.md)가 기준입니다.

## 화면에 도착하기까지

| 단계 | 담당 | 결과 |
|---|---|---|
| 자료를 찾아 의미·출처 확인 | A | 실제 구매 JSON과 출처 기록 |
| 같은 물품의 비교 대상 선택·계산 | B | 단가 차이·비교 목록·한계 |
| 질문 해석·근거 설명 | C | 검색 조건·검증된 설명 또는 기본 문장 |
| 시민이 읽을 화면 제작 | D | 카드 목록·가격 막대·상세 패널 |
| 환경·서버·모듈 연결 | E | 실행 가능한 웹 서비스 |

## 서비스의 경계

첫 대상은 물품 구매이며 용역·공사는 포함하지 않습니다. 시중가 비교는 별도 가격 자료가 확인된 경우만 제공합니다. 가격 차이가 있다는 이유로 부패·낭비를 판정하지 않고, 비교가 어려우면 그 이유를 표시합니다.

같은 기준을 모든 기록에 적용하고 비교 근거를 공개합니다. 특정 기관에 유리하거나 불리하도록 임의로 비교 대상을 고르지 않습니다. 기관별 청렴도 순위는 만들지 않습니다.

# 절대 하지 않을 것

1. 가격 차이를 예산 낭비·부패·불법의 증거로 단정하지 않습니다.
2. 규격·수량 단위·시점·포함 비용을 무시하고 비교하지 않습니다.
3. LLM이 만든 가격·출처·제품 사양을 사실로 저장하지 않습니다.
4. 비교군·분모·기간 없이 기관 순위나 점수를 공개하지 않습니다.
5. 차액을 확정 절감 가능액으로 부르지 않습니다.
6. 결측을 0으로 채우거나 자료 부족을 정상 판정으로 바꾸지 않습니다.
7. 동일 계약의 변경 이력을 별도 구매처럼 중복 집계하지 않습니다.
8. API 키·토큰·개인 연락처를 저장소·로그·화면에 노출하지 않습니다.
9. 출처·이용 조건을 확인하지 않은 원본 데이터나 상품 이미지를 재배포하지 않습니다.
10. 합성 데이터·예시 결과를 실제 공공기관의 분석 결과처럼 제시하지 않습니다.
11. AI 설명 실패 때문에 계산된 사실을 숨기거나 생성된 설명으로 빈 근거를 메우지 않습니다.
12. 정치적 성향에 따라 데이터 선택·비교 기준을 바꾸지 않습니다.

## 각자 작업에서 확인할 것

| 담당 | 제출 전 확인 |
|---|---|
| A | 원본·이용 조건·제품 규격·개인정보·출처 확인 |
| B | 계산 분모·단위·대상 제외·표본 조건·null 처리 |
| C | 허구의 숫자·출처·원인 제거, 실패 시 기본 설명 |
| D | 차액을 절감액으로 표기하지 않기, 조건·기준일 표시 |
| E | 키 비노출, 실제·합성 분리, AI 실패와 수치 조회 분리 |

문제가 있으면 해당 결과를 숨기거나 정상으로 표시하지 않고 이유를 전달합니다. 구체적인 확인 절차는 [검증 계획](testing.md)을 따릅니다.

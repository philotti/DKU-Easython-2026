# 완성까지의 작업 순서

대회일은 **2026-11-14**입니다. 시작·종료 시각과 제출 마감은 아직 확인해야 합니다.

시간 배분 대신 산출물이 연결되는 순서로 진행합니다. 각 단계의 확인이 끝나면 다음 단계로 갑니다. 역할별 정확한 파일·작업은 [역할 문서](roles/README.md)를 읽습니다.

| 순서 | 할 일 | 담당 | 다음으로 넘어가는 기준 |
|---|---|---|---|
| 1 | 기본 실행 환경·공통 합성 예제 제공 | E | 네 팀원이 자기 입력 예제를 열 수 있음 |
| 2 | 실제 데이터 표본·가격 의미·출처 확인 | A·B | 비교 가능한 제품·기관·단가가 확인됨 |
| 3 | 카드·상세 화면 / 계산 함수 / AI 기본 설명 병행 | D / B / C | 같은 예제로 화면과 수치가 일치함 |
| 4 | 실제 JSON → 검색 → 비교 → 화면 연결 | E·전원 | 실제 카드의 원본 근거를 열 수 있음 |
| 5 | 자연어 조건 추출·AI 설명 연결 | C·E·D | 실패해도 기본 검색·수치·근거 유지 |
| 6 | 시중가 자료가 있으면 별도 비교 연결 | A·B·E·D | 동일 제품·가격 조건·출처 확인, 없으면 없음 표시 |
| 7 | 사진 기준 화면 검수·오류 확인 | D·전원 | screen-spec의 체크리스트 통과 |
| 8 | 발표·녹화·실행 안내·제출 확인 | 전원 | 다른 노트북에서 시연 재현 |

실제 자료가 아직 없어도 공통 합성 예제로 화면과 함수를 만들 수 있습니다. 합성 결과를 실제 분석 성과로 발표하지 않습니다. 실제 자료가 비교 불가능하면 A·B·E가 범위를 다시 정합니다.

## 이번에 만들지 않는 것

모델 학습, 회원가입, 지도, 전국 실시간 수집, 기관 청렴도 순위, 새로운 통계 모델 연구. 카드 목록과 상세 근거 화면은 필수입니다. 시중가 비교 영역은 준비하되 실제 근거가 없으면 비워 두고 기관 간 가격을 시중가로 바꾸어 쓰지 않습니다.

## 제출 전 실제 행동

- [ ] 시민처럼 질문하고 필터를 바꾸어 본다.
- [ ] 다른 카드 두 개를 열어 상세 내용이 각각 맞는지 본다.
- [ ] 원본과 구매 가격·비교 기준·계산 결과를 대조한다.
- [ ] 시중가 없음·조건 불명·빈 결과를 열어 본다.
- [ ] Gemini 실패를 재현하고 카드가 유지되는지 본다.
- [ ] 작은 화면에서 상세 패널을 끝까지 읽어 본다.
- [ ] 다른 팀원이 실행 문서만 보고 서비스를 켠다.
- [ ] 발표에 데이터 기준일·분석 범위·한계를 넣는다.

## 2026-11-13 · 초보 팀원을 위한 작업 지침으로 개정

이전 시간표 방식은 사용자 요청으로 폐기했습니다. 역할별 만들 파일·작업 순서·입출력·검증 방법으로 대체하고 참고 사진의 카드 목록·가격 비교 막대·오른쪽 상세 패널을 완성 기준으로 문서화했습니다. 개발 경험이 있는 사용자에게 E를 추천하되 배정은 미확정입니다. 기술 후보와 함수·파일 경로는 구현 설계안이며 실행 완료를 뜻하지 않습니다.

## 2026-11-13 · 공통 문서 역할 일치

개요·설계·데이터·계약·검증·시연 문서를 A~E의 파일과 전달 관계에 맞췄습니다. C는 검색 조건 해석, E는 실제 JSON 조회·필터를 담당합니다. 가격 계산 함수는 compare_purchase, AI 함수는 parse_query/explain_analysis로 제안합니다. 숫자는 내부 JSON에서 십진 문자열로 보존하는 안이며 공통 예제를 만들 때 확정합니다. 실제 스택·데이터·모델 호출·비교 정책은 여전히 미확정입니다. 모델 학습과 별도 실험은 하지 않습니다.

# 실제 시연 구매 자료 조회 API

두 연도의 도청 구매와 서울·부산·대전 구매 기록 총 47,795건을 읽어 검색·조회합니다. B의 비교 함수는 연결했지만 실제 정책은 아직 등록되지 않았으므로 모든 분석 응답은 `unavailable`, 가격 차이·기준은 `null`입니다. 구매 단가는 확인된 원본 자료이며 차액이나 부패 판단이 아닙니다.

## 실행

macOS/Linux, 저장소 루트에서:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-server.txt -r requirements-dev.txt
.venv/bin/python -m uvicorn budget_transparency.api.server:app --app-dir src --host 127.0.0.1 --port 8000 --reload
```

Windows PowerShell에서는 `.venv/bin/python`을 `.venv\Scripts\python.exe`로 바꾸고 `python3 -m venv .venv` 대신 `py -3 -m venv .venv`를 사용합니다. 종료는 서버 터미널에서 Ctrl+C입니다. 8000번이 이미 사용 중이면 이전 서버를 종료하거나 `--port 8001`을 쓰세요. API 주소: `http://127.0.0.1:8000/docs`.

## 현재 구현된 요청

- `GET /api/options`: 연간 구매 자료의 기관·물품 ID 목록.
- `GET /api/purchases`: 구매 목록. `q`, `agency_id`, `item_id`, `date_from`, `date_to`, `status`, `comparison_type`, `sort`, `page`, `page_size` 사용 가능.
- `GET /api/purchases/{record_id}`: 상세. record_id에 `/`가 포함되므로 클라이언트에서 ID를 URL 인코딩합니다. 목록 응답의 해당 항목과 동일합니다.

예: `http://127.0.0.1:8000/api/purchases?agency_id=6410000&q=Windows`는 경기도 구매 중 Windows가 품목명·모델·기관명에 포함된 건만 반환합니다. q는 대소문자를 구분하지 않는 부분 문자열입니다. 비교 대상 계산에 검색 조건을 재사용하지 않습니다. 오류는 계약의 400/404 형식입니다.

`comparison_type=market`도 현재는 비교 불가를 반환합니다. 비교 결과가 없으므로 `difference_pct_desc`는 `item_id`가 있을 때만 허용하고 모두 ID 순입니다. `status=unavailable` 외 상태로 필터하면 결과가 없습니다.

## 계약상의 임시 표시

분석 응답 v1은 정책 ID·기간을 필수로 요구합니다. 실제 정책이 없으므로 `policy_id: not-configured`는 **실제 정책이 적용되지 않았다는 예약값**입니다. `comparison_period`에는 연간 원본 자료 수집 범위인 `2024-11-14`~`2026-11-13`을 넣습니다. 이것은 실제 비교 기간이 아니며 `limitations`에도 명시합니다. `method_version: unit-price-v1`은 응답 계약 값이지 계산 실행 증거가 아닙니다. `dataset_version`은 세 구매 파일의 바이트 길이와 내용을 순서대로 결합해 계산한 SHA-256입니다. 실제 정책을 등록하면 B 함수의 분석 응답으로 교체됩니다.

실제 기록의 `source_url`이 null인 경우 원본 링크를 만들지 않습니다. `source_id`, `source_record_id`와 [출처 문서](../../../data/sources/purchases.md)로 추적합니다.

## 상세 설명

`GET /api/explanations/{record_id}?comparison_type=agency`는 서버가 조회한 분석 응답을 C의 설명 함수에 전달합니다. 상세 패널은 기본 안내를 먼저 표시하며 사용자가 AI 확인 사항을 요청할 때만 모델을 호출합니다. 같은 기록·유형·데이터 버전·모델의 성공 응답은 서버 메모리에 5분, 실패 응답은 15초 보관해 반복 호출을 줄입니다. Gemini 응답은 최대 30초 기다리며 자동 재시도는 하지 않습니다. 사용자가 AI 확인 사항을 요청하고 `.env`의 `GEMINI_API_KEY`와 `GEMINI_MODEL`이 모두 있으면 Gemini를 호출하고, 없거나 호출·응답 검증에 실패하면 `mode: fallback`으로 기본 안내를 반환합니다. `mode: ai`는 모델이 고정된 확인 사항의 ID를 선택했다는 뜻이며 자유 문장이나 가격을 생성하지 않습니다. 키 설정 후 서버를 재시작하세요. 실제 모델 호출은 아직 검증하지 않았습니다.

## 비교 함수 연결

실제 비교 정책 `data/demo/comparison-policy.json`이 등록되면 구매 전체와 `data/shared/provinces-20251114-20261113/market-prices.json`을 B 비교 함수에 전달합니다. 정책은 [비교 규칙](../../../docs/contracts/comparison-policy.md)에 따라 A·B·E가 정해야 하며 합성 예제 정책을 실제 분석에 사용하지 않습니다. 정책이 없으면 기존 분석 불가 응답을 반환하고, 잘못된 정책이나 시중가 데이터는 서버 오류로 처리합니다. 정책 적용 시 데이터 버전에는 구매 데이터, 시중가와 정책이 반영됩니다. 현재 실제 구매 기록은 상태·비용 조건이 미확인이라 정책을 등록해도 비교 가능한 수치가 나온다고 보장할 수 없습니다.

## 조건 미확인 참고 비교

`GET /api/preliminary/{record_id}?comparison_type=agency|market`는 엄격한 비교 v1과 별도로 실제 데이터의 참고 가격 차이를 계산합니다. 기관 간은 `same-items.json`의 동일 품목 묶음을 구매 원본 및 연결표와 대조하여 다른 기관의 구매 기록을 후보로 사용합니다. 묶음이 없는 경우 물품 ID·모델·규격·단위·통화가 모두 일치하는 다른 기관 구매를 사용합니다. 구매일 180일 이내의 같은 수량을 우선하며 다른 기관 3곳·구매 5건 미만이면 수량이 0.5~2배인 후보를 사용합니다. 유사 수량도 3곳·5건 미만이면 계산하지 않습니다. 기관별 구매 단가의 중앙값을 각각 구한 후 그 중앙값으로 기준을 계산합니다. 표본·기간·수량 범위는 임시 기준이며 통계적 유의성을 보장하지 않습니다. 시중가는 물품 ID·모델·규격·단위·통화가 모두 일치하고 연결표에서 verified인 기록의 판매처별 최신 가격 중앙값을 사용합니다. 가격은 양수여야 합니다. 현재 수집 범위의 자료만 씁니다. 기관 간 참고 비교는 다른 기관 3곳·구매 5건 이상을 요구하며 시중가에는 별도 표본 최소값을 두지 않습니다. 중복되지 않은 판매처만 사용합니다. 상태 unknown을 허용하고 수량·세금·배송·설치 등 조건이 서로 다르거나 확인되지 않을 수 있음을 명시합니다. 이 계산은 이상·부패 판정이나 엄격한 비교 가능 판정이 아닙니다. 시중가는 구매 당시 가격이 아닌 조사일의 가격입니다. 상세 화면에서 참고 수치와 원본 근거를 확인할 수 있습니다. AI에는 참고 비교의 가능 여부·기준 유형·한계만 전달하며 가격·차액은 전달하지 않습니다. 숫자는 서버의 계산값으로 화면에 표시합니다.

목록 카드는 `GET /api/preliminary?comparison_type=agency&record_id=...`에 ID를 반복해 한 번에 최대 100건의 참고 수치를 요청합니다. 응답에는 상세 근거 원문을 포함하지 않으며 상세 보기에서 따로 조회합니다. 화면의 상태 필터와 차이율 정렬은 참고 계산이 아닌 엄격한 비교 v1을 기준으로 합니다.

## 구매 건별 참고 순위

`GET /api/preliminary-rankings?page=1&page_size=20`은 기관 간 참고 차이율이 있는 구매만 내림차순으로 반환합니다. 금액은 서로 합산하지 않으며 차이율이 같은 경우 구매 ID 순서입니다. `total`은 참고 수치가 있는 구매 건수, `excluded_count`는 차이율이 없는 구매 건수입니다. 기간과 한계도 포함합니다. 구매별 목록이므로 같은 기관이 여러 번 나올 수 있고 기관 평가나 공식 이상치 순위가 아닙니다. 순위는 데이터 파일 변경 시 재계산됩니다.

구매 내역 기본 정렬은 `sort=preliminary_available_desc`로 참고 차이율이 있는 구매를 먼저 표시하고 각 그룹 안에서는 구매일 최신순입니다. `GET /api/preliminary-summary?comparison_type=agency|market`은 검색·필터 적용 전 전체 구매 건수와 해당 유형의 참고 비교 가능 건수를 제공합니다. 엄격 비교 가능 건수와는 다릅니다.

기관 선택의 전남광주특별시는 무안청사의 원본 기관코드 6460000과 6130769를 함께 조회하는 범위입니다. 두 코드를 묶어도 응답과 출처의 원본 기관코드는 그대로 유지합니다. 다른 청사는 수집 범위에 포함되지 않습니다.

`GET /api/region-distribution?agency_id=...`는 지도에서 선택한 본청의 구매 건수, 기관 간 참고 계산 건수와 제외 건수, 반올림된 차이율이 양수·0·음수인 건수를 반환합니다. 0은 차이율 소수 둘째 자리 반올림 결과이며 정확히 같은 금액만을 의미하지 않습니다. agency_id가 없으면 전체 구매 기준입니다. 도청의 청렴도나 이상 거래를 판단하는 지표가 아닙니다.

지역 분포의 `monthly_purchases`는 해당 지역의 구매 품목 기록을 2024-11~2026-11 월별로 집계합니다. 첫 달과 마지막 달은 부분월이고 2026-12 자료는 없습니다. 품목 기록 수는 계약 건수나 지급·예산 집행액이 아니며, 이 자료만으로 연말 예산 소진이나 수의계약 분할 의도를 판단할 수 없습니다.

`GET /api/region-comparison`은 12개 본청별 전체 구매, 참고 비교 건수와 기준보다 높은 건수를 반환합니다. 그래프의 비율 분모는 각 본청의 참고 비교 건수입니다. 표본 및 품목 구성이 달라 기관 평가나 시간 추세를 의미하지 않습니다.

두 연도 간 동일한 시중가 ID는 내용이 완전히 같으면 한 번만 사용하며, 값이 다르면 오류로 처리합니다. 연도별 동일 품목 그룹 ID는 품목·규격·단위·통화가 일치할 때 합쳐 구매일 180일 조건 안에서 비교합니다. 구매 ID는 연도 간 중복을 허용하지 않습니다.

서울·부산·대전 본청 자료는 2025-11-14부터입니다. 그 이전 월은 0건이 아니라 자료 없음으로 표시하며 2025년 11월은 부분월입니다. 해당 구매 데이터에는 시중가 연결표가 없으므로 이를 임의로 만들지 않습니다. 모델·품목 ID·규격·단위·통화가 모두 일치하고 기존 품목 묶음이 유일한 경우에만 다른 지역과 참고 비교 후보로 연결합니다.

## 지역 구매 기록 보고서

`GET /api/region-report?agency_id=...`은 코드가 작성한 월별 구매 품목 기록 요약과 참고 단가 비교 현황을 반환합니다. `ai=1`은 사용자가 요청한 경우에만 Gemini에 지역별 집계와 허용된 확인 항목을 전달해 1~3개 ID를 선택하게 합니다. 모델은 자유 문장·가격·원인을 생성하지 않으며 허용 목록 밖의 응답은 버립니다. 성공은 5분, 실패는 15초 동안 서버 메모리에 보관합니다. 구매 품목 행의 월별 건수는 실제 지급·예산 집행액이 아니므로 월별 지출 금액이나 연말 예산 소진 여부를 계산하지 않습니다. 구매 상세에는 AI 요청 UI가 없습니다.

지역 보고서는 같은 날짜·품목명별 구매 품목 행을 집계해 가장 많은 사례와 원본 식별자 최대 10개를 표시합니다. 같은 이름은 다른 규격일 수 있고 여러 행이 하나의 계약에 속할 수 있습니다. 개별 단가·수량은 근거에만 표시하고 모델에는 보내지 않습니다. 외부 검색과 실제 사건의 확인은 연결하지 않았습니다. AI가 제시하는 가능성은 검증 전 확인 사항입니다.

참고 보고서는 같은 품목명이 기록된 날이 6일 이상인 경우, 하루에 해당 품목 행이 10건 이상이며 기록이 있는 날들의 일별 중앙값의 3배 이상이면 추가 확인 사례로 표시합니다. 이는 임의의 탐색 기준이며 이상 거래나 통계적 유의성을 뜻하지 않습니다. 모델은 허용된 확인 사항을 선택하고 외부 검색은 실행하지 않습니다.
